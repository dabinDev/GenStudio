# 塞隆studio Operations README

## Production Domain

Use `https://studio.cylonai.cn` for the 塞隆studio frontend and backend origin. Official-site SSO should redirect users to:

```text
https://studio.cylonai.cn/auth/callback?code=xxx
```

The `code` is not manually entered in production. The backend exchanges it through `OFFICIAL_AUTH_EXCHANGE_URL`, writes the `genstudio_session` HttpOnly cookie, then redirects back to the frontend hash route.

## Required Environment

Start from `server/.env.production.example` and set real values:

- `GENSTUDIO_ENV=production`
- `GENSTUDIO_SECRET_KEY`: long random value, backed up securely. This key protects sessions and encrypted API keys.
- `GENSTUDIO_COOKIE_SECURE=true`
- `GENSTUDIO_ENABLE_DEV_LOGIN=false`
- `GENSTUDIO_AUTO_CREATE_TABLES=false`
- `GENSTUDIO_CORS_ORIGINS=https://studio.cylonai.cn`
- `GENSTUDIO_ADMIN_IDENTIFIERS`: comma-separated non-email admin identifiers, such as a local username.
- `OFFICIAL_AUTH_EXCHANGE_URL`, `OFFICIAL_AUTH_CLIENT_ID`, `OFFICIAL_AUTH_CLIENT_SECRET`
- `DATABASE_URL` for the production MySQL database `genstudio`
- `OBJECT_STORAGE_ENABLED=true`
- `OBJECT_STORAGE_ENDPOINT_URL`, `OBJECT_STORAGE_BUCKET`, `OBJECT_STORAGE_ACCESS_KEY_ID`, `OBJECT_STORAGE_SECRET_ACCESS_KEY`
- `OBJECT_STORAGE_PUBLIC_BASE_URL`, the CDN/public base URL for uploaded reference assets

The app refuses to start in production when these safety checks are not met.

## Database Migration

Production must not rely on startup auto-create. Apply the initial schema before first deploy:

```bash
mysql -h <host> -u genstudio -p genstudio < server/migrations/001_initial_schema.sql
```

For later schema changes, add a new numbered SQL file under `server/migrations/` and apply it during maintenance. Keep backups before every migration.

## Backup

Back up at least these tables: `users`, `user_credentials`, `sessions`, `api_keys`, `models`, `sub_models`, `conversations`, `conversation_messages`, `generated_assets`, `call_logs`.

Example:

```bash
mysqldump -h <host> -u genstudio -p --single-transaction --routines --triggers genstudio > genstudio-$(date +%F-%H%M).sql
```

Store `GENSTUDIO_SECRET_KEY` with the backup set. Without it, encrypted user API keys cannot be decrypted after restore.

## Health Checks

Use:

```text
GET /api/health
```

Expected production result:

```json
{"status":"ok","database":"ok","storage":"configured"}
```

If storage is `not_configured`, uploads may still fall back during development, but production startup will be rejected.

## Upload Storage

Production uploads use an S3-compatible `PUT` presigned URL generated by 塞隆studio. Configure the storage endpoint, bucket, region, access key, secret key, optional object key prefix, and public CDN/base URL through the `OBJECT_STORAGE_*` variables. Development without object storage can still use the legacy provider `/api/upload/presign` compatibility path, but production requires first-party object storage so reference images and videos are not stored as local data URLs.

## Reverse Proxy

Nginx minimum shape:

```nginx
server {
  listen 443 ssl http2;
  server_name studio.cylonai.cn;

  client_max_body_size 80m;

  location /api/ {
    proxy_pass http://127.0.0.1:8000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto https;
  }

  location /auth/ {
    proxy_pass http://127.0.0.1:8000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto https;
  }

  location / {
    root /srv/genstudio/fronted/dist;
    try_files $uri $uri/ /index.html;
  }
}
```

## Rate Limits

The app includes an in-process limiter for login, registration, model list/test, generation, video query, and upload-presign routes. For multiple backend instances, mirror these limits at the gateway or move to Redis-backed limiting.

## Long Video Jobs

The current backend persists submitted video task messages in conversations and stores failed query records with retry enabled. For high traffic production, move video creation/query to a queue and worker model so jobs survive deploys and client disconnects.
