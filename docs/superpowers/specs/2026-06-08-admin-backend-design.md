# 管理员后台与公用模型治理设计

日期：2026-06-08

## 背景

GenStudio 当前已经支持用户登录、公用模型展示、管理员设置公用模型，以及普通用户在设置页管理自己的模型。但后台能力仍混在普通设置页中，缺少取消公用、用户管理、提示语治理、运营统计和创作记录查看能力。

本设计将普通用户设置页和管理员后台拆成两套体验：

- 普通用户继续使用 `#/settings`，只管理自己的模型；公用模型只读可用。
- 管理员新增 `#/admin`，集中管理公用模型、提示语模板、用户、运营统计、创作记录和操作审计。

## 设计原则

- 权限在服务端强制校验。前端隐藏按钮只是体验优化，不能作为安全边界。
- 后台默认拒绝非管理员访问。所有 `/api/admin/*` 接口都必须通过管理员鉴权。
- 敏感信息脱敏。后台记录和响应不展示完整 API Key、Cookie、密钥明文或上游私密配置。
- 第一版先闭环管理能力，不引入复杂计费、审批流、角色系统和模板版本回滚。
- 记录类页面优先复用现有会话、消息、资产和调用日志，必要时补充字段，而不是重建一套记录系统。

安全参考：

- OWASP Authorization Cheat Sheet 建议每个请求都校验权限并默认拒绝未授权访问。
- OWASP Logging Cheat Sheet 建议避免在日志中保存敏感信息，并对日志展示做脱敏和注入防护。

## 信息架构

管理员后台路由为 `#/admin`。后台包含 8 个 tab：

1. 运营面板
2. 公用模型配置
3. 提示语模板
4. 用户管理
5. 文案记录
6. 生图记录
7. 视频记录
8. 操作记录

普通用户没有后台入口。非管理员直接访问 `#/admin` 时，前端展示无权限页面；后端接口返回 403。

## Tab 2：公用模型配置

### 第一版功能

- 模型列表：
  - 全部模型
  - 公用模型
  - 私有模型
  - 文案创作
  - 图片创作
  - 视频创作
  - 搜索模型名称、厂商、备注、子模型名称
- 单个模型操作：
  - 设为公用
  - 取消公用
  - 编辑公用展示名
  - 编辑公用备注
  - 编辑输入框默认 hint
  - 编辑图标资源
  - 设置标签
  - 设置 AI 提示词优化启用 / 禁用
  - 查看绑定的主模型和子模型
- 批量操作：
  - 批量设为公用
  - 批量取消公用
  - 批量设置推荐 / 维护中标签
- 图标资源：
  - 选择内置图标名称
  - 填写 icon URL
  - 上传图标资源
  - 保存后同步展示到模型选择器和设置页
- 模型可用能力：
  - 是否允许用于文案创作
  - 是否允许用于图片创作
  - 是否允许用于视频创作
  - 第一版可继续沿用模型原始 capability，后台只展示和校验，不做跨能力改造
- 模型参数：
  - 展示 catalog 中的尺寸、比例、分辨率、时长等参数
  - 后台可设置前台默认值
  - 前台只能展示当前模型支持的参数

### 普通用户看到的公用模型

- 可直接使用。
- 不可编辑。
- 不可删除。
- 不可查看密钥。
- 用特殊边框和 tag 标记“公用模型”。

### 后续增强

- 公用模型排序权重
- 默认推荐模型
- 灰度发布

## 后端 API 设计

所有接口均要求管理员权限：

- `GET /api/admin/overview`
  - 运营面板总览。
- `GET /api/admin/overview/users`
  - 按用户统计调用。
- `GET /api/admin/overview/models`
  - 按模型统计调用。
- `GET /api/admin/models`
  - 后台模型列表。
- `PUT /api/admin/models/{model_id}`
  - 编辑公用展示字段、hint、icon、标签、提示语启用状态、默认参数。
- `POST /api/admin/models/{model_id}/publish`
  - 设置公用。
- `POST /api/admin/models/{model_id}/unpublish`
  - 取消公用。
- `GET /api/admin/prompt-templates`
  - 模板列表。
- `PUT /api/admin/prompt-templates/{template_id}`
  - 保存模板。
- `POST /api/admin/prompt-templates/test`
  - 测试模板优化效果。
- `GET /api/admin/users`
  - 用户列表。
- `PUT /api/admin/users/{user_id}`
  - 编辑用户资料。
- `POST /api/admin/users/{user_id}/disable`
  - 禁用用户。
- `POST /api/admin/users/{user_id}/enable`
  - 启用用户。
- `POST /api/admin/users/{user_id}/delete`
  - 软删除用户。
- `POST /api/admin/users/{user_id}/restore`
  - 复权用户。
- `GET /api/admin/records/text`
  - 文案记录。
- `GET /api/admin/records/images`
  - 生图记录。
- `GET /api/admin/records/videos`
  - 视频记录。
- `GET /api/admin/audit-logs`
  - 操作记录。

## 前端数据流

### 路由

- 新增 `admin` view。
- `#/settings` 继续作为普通设置页。
- 管理员登录后顶部或侧边栏显示“后台”入口。
- 非管理员打开 `#/admin` 显示无权限提示。

### 普通设置页

- 只展示当前用户模型和公用模型。
- 私有模型可编辑、删除、测试。
- 公用模型只读，可使用，不可编辑或删除。

### 管理员后台

- 使用单独的 `adminState` 管理筛选、分页、详情抽屉和表单。
- 管理员后台不复用普通设置页的新增模型弹窗。
- 公用模型配置保存后刷新全局模型列表。

### 提示词优化

前台点击 AI 优化图标时：

1. 发送当前 `capability`、`modelGroupId`、`subModelId`、原始提示词和参数。
2. 后端先查模型专属模板。
3. 找不到则使用能力类型默认模板。
4. 模板禁用时返回清晰错误。
5. 优化结果回填输入框。

## 权限与错误处理

- `/api/admin/*` 使用统一管理员依赖。
- 非登录用户返回 401。
- 已登录非管理员返回 403。
- 禁用或软删除用户不能登录、不能访问受保护接口。
- 主管理员账号不能被后台禁用、删除或复权覆盖。
- 后台所有写操作产生操作记录。
- 写操作失败也记录失败摘要。
- 所有后台列表分页，避免一次返回过多数据。

## 验收测试

### 后端测试

- 非登录访问 `/api/admin/*` 返回 401。
- 非管理员访问 `/api/admin/*` 返回 403。
- 管理员可以设置公用和取消公用。
- 普通用户不能编辑、删除公用模型。
- 提示语模板按模型专属优先、默认模板兜底。
- 禁用用户后 session 失效或后续接口返回 403。
- 软删除用户后不可登录。
- 后台记录接口不返回完整 API Key。
- 操作日志写入成功且敏感字段脱敏。

### 前端测试

- 普通用户看不到后台入口。
- 管理员能打开 `#/admin`。
- 普通设置页仍可添加、测试、编辑私有模型。
- 公用模型在普通设置页只读展示。
- 公用模型配置可设为公用和取消公用。
- 提示语模板保存后，文案、图片、视频页面 AI 优化图标都能使用新模板。
- 文案记录能展示提示词和 Markdown 回复。
- 生图记录能展示参考图和结果图。
- 视频记录能展示 taskId、查询状态和视频播放。
- 用户管理可启用、禁用、软删除和复权普通用户。

## 非目标

- 第一版不做复杂角色系统。
- 第一版不做计费结算。
- 第一版不做审批流。
- 第一版不做模板版本回滚。
- 第一版不向普通用户展示上游供应商、密钥、完整 baseURL 或内部路由细节。
