# Admin Console Redesign Design

## Goal

把塞隆 Studio 管理后台从平铺式设置页，重构成独立、紧凑、可扫描的运营控制台，同时保留现有管理员功能和接口。

## Reference

参考 Sub2API 后台的信息架构：固定侧边栏、顶部状态栏、KPI 卡片、筛选工具条、密集表格、图表化统计和记录明细。GenStudio 不复制 Sub2API 的计费/API Key 语义，只借鉴管理台布局方式。

## Admin Shell

后台保持单页面独立呈现，不嵌入创作端侧栏。整体结构为左侧固定导航、右侧顶部状态栏、主体滚动内容。左侧导航按“总览、模型、用户、记录、审计”分组，每个入口带简短图标和说明。顶部展示环境、当前管理员、刷新当前页、返回创作台。

## Pages

运营面板展示总调用、成功、失败、平均响应、公用模型调用、私有模型调用，并提供成功率环图、模型归属环图、能力分布、慢响应模型、模型 Top、用户 Top。

公用模型配置以表格为主，支持能力 tab、公开状态、搜索。模型行显示图标、名称、厂商、能力、公开状态、主模型、提示优化状态，操作包括编辑配置、设为公用、取消公用。编辑区保留展示名、图标 URL、描述、输入 hint、标签、AI 优化开关、默认参数 JSON。

提示语模板采用左侧模板库、右侧编辑器、下方测试预览。管理员可以按能力和模型绑定模板，启用或禁用 AI 文案优化模板，并测试结果。

用户管理采用搜索工具条和密集用户表格。用户行展示昵称/ID、邮箱/手机、状态、更新时间和操作。管理员账号不允许禁用、删除、恢复。

文案、生图、视频记录保留独立 tab，也提供跨类型切换。工具条支持类型、用户模糊搜索、状态和模型 ID。文案记录显示提问和回答，图片/视频记录显示请求、响应媒体、任务 ID，调试 JSON 默认收起。

操作记录以审计表格呈现，支持动作和管理员 ID 筛选，展示时间、动作、目标、状态、摘要。

## Visual Direction

使用浅色运营控制台风格：白色面板、低饱和冷色背景、蓝绿强调色、8px 以内圆角、清晰边框、紧凑表格、少量环图和进度条。后台优先使用 CSS 与已有模型图标，不额外生成装饰性位图。

## Testing

前端新增可测试的后台展示配置模块，验证导航分组、tab 建议、记录页建议等元数据完整。视觉通过本地浏览器逐页截图检查，功能通过现有 Vitest 和生产构建验证。
